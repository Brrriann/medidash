# 건강식품 셀러 B2B 대시보드 — 인체 인터랙티브 지도 UI 기획서

> 문서 버전 v1.0 | 작성일 2026-07-22 | 대상: 개발팀
> 원본: 고객 제공 워드 문서(.docx)를 마크다운으로 변환한 것. 내용 동일.

## 1. 프로젝트 개요

건강식품 셀러가 부위(증상) → 원료 → 상품 등록까지 원스톱으로 처리할 수 있는 B2B 웹 대시보드. 핵심 진입점은 인체 인터랙티브 지도 UI이며, 클릭 한 번으로 특징·추천원료·기전원리·셀링포인트를 확인하고 3개 도매몰(건온연B2B, 건강산, 유픽B2B) 상품 소싱으로 연결된다.

## 2. 분류 체계 확정안 (3단 구조)

| 단계 | 깊이 | 개수 | 목적 | UI 표현 |
|---|---|---|---|---|
| 대분류 | 인체 계통 | 10개 | 지도 클릭 진입점 | 인체 SVG 클릭 영역 |
| 중분류 | 부위/기능 | 3~6개/계통 | 셀러 판매 각도 결정 | 사이드 패널 카드 |
| 소분류 | 증상 키워드 | 5~10개/중분류 | 원료·셀링포인트 매핑 트리거 | 태그 칩(chip) |

### 채택 근거

- 인지 부하 최소화: 대분류 10개는 인체 SVG에서 한눈에 클릭 가능한 상한선
- 식약처 공전 1:1 매핑: 기능성 분야(기억력·혈행·간·눈·면역·관절·갱년기 등)와 그대로 연결
- AI 프롬프트 안정성: 소분류 키워드 단위(예: "잔변감", "복부팽만")로 클릭 시 LLM이 일관된 원료·기전·셀링포인트를 생성

## 4. UI 인터랙션 흐름

| 단계 | 화면 | 셀러 액션 | 시스템 응답 |
|---|---|---|---|
| 1 | 인체 정면/후면 SVG | 부위 클릭 (예: 배) | 대분류(소화·대사계) 활성 + 중분류 카드 노출 |
| 2 | 중분류 카드 리스트 | "장" 선택 | 소분류 증상 칩 5~10개 표시 |
| 3 | 소분류 칩 선택 | "과민성장" 클릭 | 우측 4-Tab 상세 패널 오픈 |
| 4 | 우측 패널 | 탭 전환 | ① 특징 ② 추천원료 ③ 기전원리 ④ 셀링포인트 |
| 5 | 하단 CTA | "이 원료로 상품 소싱" | 3개 도매몰 검색 결과 통합 노출 |
| 6 | 소싱 결과 카드 | "상품 선택" | 썸네일·상품명·태그·마진 계산 자동 프리셋 |

## 5. 4-Tab 상세 패널 스펙

| 탭 | 구성 요소 | 데이터 소스 | AI 프롬프트 예시 |
|---|---|---|---|
| ① 특징 | 부위 개요, 관련 증상 요약 | 자체 DB + Wiki | "○○ 부위의 해부학적 역할과 대표 증상 3줄 요약" |
| ② 추천원료 | 원료명, 인정형/고시형, 일일 섭취량 | 식약처 기능성 원료 DB | "○○ 증상 개선에 도움을 주는 식약처 인정 원료 Top 5" |
| ③ 기전원리 | 흡수·작용경로 다이어그램 | LLM + 자체 이미지 | "○○ 원료가 ○○ 부위에 작용하는 기전을 4단계로 설명" |
| ④ 셀링포인트 | 카피 후보 3~5개 (법적 안전 표현) | LLM + 광고법 필터 | "질병 예방·치료 표현 제외, 도움을 줄 수 있음 표현으로 카피 5개" |

### 썸네일 자동 생성 프롬프트 템플릿

```
[원료명]을(를) 강조한 건강기능식품 정사각형 썸네일. 배경: [부위 관련 컬러],
좌측 상단 [건강기능식품 마크], 중앙 [제품 이미지 mockup], 하단 [핵심 카피 1줄].
텍스트는 한국어, 굵은 산세리프, 대비 강한 색상.
```

## 9. 법적 리스크 대응

| 리스크 | 영역 | 대응 |
|---|---|---|
| 회원제 B2B 무단 크롤링 | 개인정보/이용약관 | 파트너 API 계약 or 셀러 계정 프록시 |

| 개별인정형 원료 표기 오류 | 식약처 광고 심의 | 식약처 DB 실시간 조회 후 인증 원료만 자동 배지 |
| 원산지·성분 오표기 | 식품표시광고법 | 도매몰 원본 필드 그대로 표시 + 셀러 확인 체크박스 |
